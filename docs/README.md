# Isen documentation

The root [README](../README.md) is the quickest route to building and running
Isen. These guides describe its public surface in more detail.

- [Language reference](LANGUAGE_REFERENCE.md) — the precise, generation-oriented
  language and shipped-runtime contract.
- [Project configuration](PROJECT_CONFIG.md) — `isen.toml`, formatter settings,
  test profiles, and linked stashes.
- [Testing](TESTING.md) — `isen test` and the opt-in `Test` space.
- [Diagnostics](DIAGNOSTICS.md) — versioned machine-readable editor and CI output.
- [Profiling](PROFILING.md) — runtime measurements and the JSON profile format.
- [Logging](LOGGING.md) — human and JSON-lines logging stashes.
- [Extension authoring](EXTENSIONS.md) — adding isolated Rust-backed spaces.
- [Releasing](RELEASING.md) — tag-triggered GitHub releases, artifacts, and
  checksum verification.
- [Development checks](DEVELOPMENT.md) — versioned pre-commit and pre-push
  hooks.
